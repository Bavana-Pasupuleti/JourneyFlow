**Global Employee Lifecycle Automation**

An enterprise platform that automates employee onboarding across multiple countries, dynamically routing compliance tasks, tax and identity documents, and approval steps based on each employee's location.

## Planned features
- Location-aware routing of compliance tasks, tax/identity documents, and approvals
- **Spring Boot** REST APIs with **PostgreSQL** data models
- **Kafka** event-driven lifecycle workflows
- **React** dashboard coordinating approvals across HR, IT, and Compliance
- Automated email and push notifications for lifecycle milestones

## Tech stack
Java · Spring Boot · PostgreSQL · Apache Kafka · React
